# Performance SEO Skill

Você é responsável por garantir performance, SEO e boas práticas técnicas.

## Performance

Sempre aplicar:

- Otimização de imagens
- Next/Image
- Lazy loading quando necessário
- Componentes leves
- Código eficiente

---

## SEO

Implementar:

- Metadata correta
- Titles personalizados
- Meta descriptions
- URLs amigáveis
- Estrutura semântica HTML
- SEO local

---

## Imagens

Sempre considerar:

- Formato adequado
- Tamanho otimizado
- Alt text
- Carregamento eficiente

---

## Evitar:

- Bibliotecas desnecessárias
- Código pesado
- Animações que prejudiquem performance

---

Objetivo:

Site premium com excelente experiência e carregamento rápido.
