1. Objetivo deste documento

Este documento define como conduzir o desenvolvimento do site Espaço Savanna utilizando Claude Code.

O objetivo é garantir consistência visual, qualidade técnica e evolução controlada do projeto.

O Claude deve atuar como parceiro de desenvolvimento e não apenas como gerador de código.

2. Regra principal de trabalho

Nunca iniciar criando páginas completas sem análise prévia.

O processo correto é:

Analisar → Planejar → Criar estrutura → Implementar → Revisar → Refinar.

Cada etapa deve preservar as decisões definidas nos documentos do projeto.

3. Primeiro comando no Claude Code

Ao iniciar o projeto, executar:

Leia todos os documentos existentes do projeto.

Analise:

- Objetivos
- Design System
- Direção de arte
- Estrutura de páginas
- Stack técnica

Não escreva código neste momento.

Primeiro apresente:

- entendimento do projeto
- arquitetura sugerida
- plano de implementação

4. Fase 01 — Arquitetura

Nesta fase o Claude deve criar:

- Estrutura de pastas
- Configuração inicial
- Design tokens
- Componentes necessários
- Estratégia de páginas


Validar antes de iniciar desenvolvimento visual.

5. Fase 02 — Design System em código

Transformar o Design System em elementos reais:

- Variáveis de cores
- Tipografia
- Espaçamentos
- Componentes base
- Estados dos elementos


Não criar páginas ainda.

6. Fase 03 — Componentes

Criar componentes reutilizáveis:

- Header
- Footer
- Buttons
- Hero sections
- Cards
- Gallery
- FAQ
- Formulários


Cada componente deve ser revisado visualmente antes de avançar.

7. Fase 04 — Desenvolvimento das páginas

Criar uma página por vez.

Ordem recomendada:

1. Home
2. O Espaço
3. Terapeutas
4. Experiências
5. Como Funciona
6. Galeria
7. Trabalhe Conosco
8. Aluguel de Salas
9. Contato


Após cada página:

- revisar desktop
- revisar mobile
- revisar conversão
- revisar fidelidade ao design

8. Como pedir melhorias ao Claude

Sempre solicitar melhorias específicas.

Exemplo:

'Melhore esta seção mantendo o Design System, sem alterar a identidade visual.'

Evitar:

'Deixe mais bonito'

Porque isso pode gerar mudanças fora da direção aprovada.

9. Controle de qualidade visual

Após cada etapa avaliar:

Visual:
- Parece premium?
- Tem personalidade?
- Está alinhado com a direção de arte?

UX:
- Usuário entende rapidamente?
- CTA está claro?

Código:
- Está organizado?
- Componentes reutilizáveis?

Performance:
- Imagens otimizadas?
- Carregamento adequado?

10. Como evitar perda de identidade

Durante alterações:

Nunca remover:

- Espaçamento generoso
- Tipografia editorial
- Cores aprovadas
- Estética premium
- Simplicidade visual


Se uma nova ideia surgir, comparar com:

'Isso melhora a experiência ou apenas adiciona elementos?'

11. Processo de revisão final

Antes da publicação:

Revisar:

Desktop:
- Todas as páginas
- Navegação
- Animações

Mobile:
- Menu
- Botões
- Imagens
- Textos

SEO:
- Titles
- Descriptions
- Estrutura HTML

Conversão:
- WhatsApp funcionando
- CTAs claros
- Formulários funcionando

12. Regra final

O objetivo não é apenas criar um site funcional.

O objetivo é criar uma experiência digital premium que represente o Espaço Savanna.

Toda decisão deve responder:

'Isso aumenta a percepção de valor da marca?'
