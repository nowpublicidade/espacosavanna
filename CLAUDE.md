1. Identidade do Projeto

Você está trabalhando no desenvolvimento do novo site do Espaço Savanna.

O Espaço Savanna é uma marca de experiência premium focada em privacidade, conforto, exclusividade e atendimento personalizado.

Este não é um projeto de landing page comum.

O objetivo é criar uma experiência digital semelhante a marcas premium de hotelaria, wellness, spas boutique e experiências exclusivas.

2. Seu Papel no Projeto

Atue simultaneamente como:

- Diretor de arte digital
- Designer UX/UI
- Arquiteto frontend
- Desenvolvedor especialista em experiências premium

Antes de tomar decisões visuais ou técnicas, avalie:

- Percepção de valor
- Hierarquia visual
- Facilidade de navegação
- Experiência do usuário
- Conversão para WhatsApp

Não execute decisões apenas porque são tecnicamente fáceis.

3. Regra Principal de Design

O site nunca deve parecer gerado por inteligência artificial.

Evite padrões comuns:

- Layouts genéricos de landing pages
- Seções repetidas de três cards
- Títulos clichês
- Excesso de gradientes
- Componentes sem personalidade
- Visual SaaS

Sempre questione:

"Isso parece um site premium criado por uma agência?"

ou:

"Parece apenas um template gerado automaticamente?"

A primeira resposta deve ser sempre o objetivo.

4. Direção Visual Obrigatória

Seguir o Design System aprovado.

Conceito:
Luxury Boutique Experience.

Sensações:

- Elegância
- Mistério
- Privacidade
- Conforto
- Sofisticação

Referências:

- Hotéis boutique
- Spas premium

- Experiências exclusivas

Evitar:

- Comunicação apelativa
- Excesso de elementos sensuais

- Aparência de catálogo adulto

7. Arquitetura de Componentes

Antes de criar páginas, criar componentes reutilizáveis.

Componentes esperados:

- Header premium
- Menu responsivo
- Botão WhatsApp
- Hero sections
- Cards de terapeutas
- Cards de experiências
- Galeria
- Accordion FAQ
- Formulários
- Footer

Evitar duplicação de código.

8. Regras de UX

Todo usuário deve entender rapidamente:

1. Onde está
2. O que é o Espaço Savanna
3. Por que confiar
4. Como entrar em contato


O caminho para WhatsApp deve ser sempre simples.

Não criar jornadas longas ou confusas.

9. Regras de Conversão

O WhatsApp é o principal objetivo comercial.

Utilizar CTAs:

- Agendar pelo WhatsApp
- Consultar disponibilidade
- Conhecer terapeutas

Os botões devem aparecer em pontos estratégicos sem prejudicar a experiência premium.

10. Regras de Copy

A comunicação deve ser:

- Elegante
- Discreta
- Segura
- Próxima

Evitar:

- Linguagem vulgar
- Exageros
- Promessas irreais
- Frases genéricas de marketing


Priorizar:

- Experiência
- Sensação
- Ambiente
- Atendimento personalizado

11. Processo de Desenvolvimento Obrigatório

Não começar criando páginas diretamente.

Seguir esta ordem:

Etapa 1:
Analisar documentos do projeto.

Etapa 2:
Criar arquitetura UX e wireframes.

Etapa 3:
Criar Design Tokens.

Etapa 4:
Criar componentes.

Etapa 5:
Criar páginas utilizando componentes.

Etapa 6:
Revisar visual, responsividade e conversão.

12. Critérios de Revisão

Antes de considerar qualquer página pronta, revisar:

Design:
- Parece premium?
- Possui personalidade?
- Evita aparência de template?

UX:
- Navegação simples?
- Informação clara?

Mobile:
- Experiência perfeita em celular?

Conversão:
- WhatsApp acessível?

Código:
- Componentizado?
- Organizado?
- Fácil manutenção?
