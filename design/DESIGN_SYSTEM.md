1. Objetivo

Este documento transforma o Design System aprovado do Espaço Savanna em regras práticas para desenvolvimento no Claude Code.

Todos os componentes, páginas e decisões visuais devem seguir estas diretrizes.

2. Conceito Visual

Direção:
Luxury Boutique Experience.

O design deve transmitir:

- Elegância
- Privacidade
- Conforto
- Exclusividade
- Sofisticação

A referência visual deve se aproximar de:

- Hotéis boutique
- Spas premium
- Marcas de perfumaria de nicho
- Experiências de luxo

3. Paleta de Cores

Cores principais:

Background profundo:
#0B0806

Texto principal:
#F2EBE0

Dourado principal:
#C6A15B

Dourado suave:
#E3CB9A

Uso:

O dourado deve ser utilizado como detalhe de sofisticação, nunca como cor dominante.

Evitar:
- Cores vibrantes
- Contrastes agressivos
- Gradientes artificiais

4. Tipografia

Títulos:

Cormorant Garamond

Uso:
- Headlines
- Títulos de seção
- Frases institucionais


Interface:

Jost

Uso:
- Menus
- Botões
- Textos corridos
- Formulários

5. Espaçamento e Ritmo Visual

Priorizar:

- Grandes áreas vazias
- Respiro entre elementos
- Hierarquia clara
- Layout editorial

Evitar:

- Blocos apertados
- Excesso de informação
- Muitas seções repetitivas

6. Componentes

Header:

- Logo em destaque
- Menu limpo
- CTA WhatsApp


Botões:

Principal:
Dourado com texto escuro.

Secundário:
Contorno discreto.


Cards:

Devem ser elegantes, com poucas informações.

Evitar cards tradicionais de SaaS.

7. Imagens

As imagens são protagonistas.

Priorizar:

- Ambientes
- Texturas
- Arquitetura
- Iluminação
- Detalhes sofisticados

Evitar:

- Banco de imagem genérico
- Fotos artificiais
- Imagens apelativas

8. Responsividade

Mobile deve ser tratado como prioridade.

Garantir:

- Navegação simples
- CTAs acessíveis
- Imagens adaptadas
- Boa leitura de textos
