DIREÇÃO CRIATIVA · SITE

Duas propostas de layout para o novo site.

Este documento apresenta duas direções visuais completas, em versão celular e computador. As telas são navegáveis: role, abra as perguntas, arraste os carrosséis.

Setembro de 2026 Versão 1 para aprovação

Como usar este documento

As duas direções têm exatamente o mesmo conteúdo e a mesma estrutura de páginas. O que muda é o tratamento visual: tipografia, uso da cor dourada, formato dos blocos e ritmo das seções.

Você não precisa escolher detalhes. Precisa escolher qual das duas parece mais com o Espaço Savanna. A partir daí eu refino a escolhida e produzo as páginas internas.

As imagens que estão no layout são demonstrativas, no desenvolvimento iremos inserir as imagens finais
